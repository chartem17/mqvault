# ADR 0007. Мови інтерфейсу

**Статус:** діє · **Дата:** 2026-11-07 (рішення власника)

## Рішення
Основна мова сайту — англійська, додаткова — українська. Вибір зберігається в cookie `mq_locale` і перемикається кнопкою EN/UA у шапці та на сторінці входу.

## Наслідки
- Вихідний текст у коді — англійський (`t("English text")`); переклад — у `src/lib/i18n/uk.ts` за точним англійським рядком; відсутній ключ падає на англійську.
- `npm test` падає, якщо `t()`/`msg()`-рядок не має українського перекладу або якщо українська захардкоджена поза словником.
- API повертає англійські повідомлення про помилки; UI показує їх через `t(error)`.

Інструкція «як додати текст» — [features/i18n.md](../features/i18n.md). Код: `src/lib/i18n/`, `src/components/providers/i18n-provider.tsx`, `src/components/settings/language-toggle.tsx`.
