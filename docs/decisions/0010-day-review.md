# ADR 0010. Розбір дня: позначка в `meta.review`, P/L не перераховується при розмітці

**Статус:** діє · **Дата:** 2026-11-07

## Рішення
- «Розбір дня» — режим журналу (`/?tab=journal&review=1`, кнопка «Розбір» у журналі, «Почати розбір» на Головній): по одній угоді, чипи замість текстових полів — сетап, емоція, «за планом» (так/ні), помилка — і нотатка в один рядок. Enter — зберегти й далі, → — пропустити, ← — назад, Esc — закрити. «День без зауважень» позначає решту угод дня розібраними, нічого в них не змінюючи.
- Черга: угоди без позначки розбору, у яких немає сетапу або емоції; групи за днем у поясі користувача, новіший день першим, у межах дня — за часом відкриття. Черга фіксується на старті, тож збережена угода не зсуває курсор.
- Позначка розбору — `journal_trades.meta.review = { reviewed_at, followed_plan }`. Без міграції: `meta` уже є, сервер зливає її з наявним вмістом (`tz_fixed` тощо лишається). Поле, яке трейдер не заповнив, лишається порожнім; нічого не вгадується.
- Чипи: спершу список стратегії рахунку (`strategy_rules.definition.review.{setups,mistakes}`, задається в конструкторі стратегії), далі значення, вже вжиті в журналі (за частотою), далі вбудовані підказки; можна додати своє. Емоції — чотири значення, які розуміє рушій (`Calm`, `Neutral`, `Tired`, `Angry`). Значення зберігаються англійською й перекладаються лише при показі.
- `followed_plan` подається в правило «Підтверджена модель входу» Strategy Control (має перевагу над висновком із mistake/setup) — основа для «Ціни порушень».
- **PATCH угоди перераховує `net_pnl`/`result_r` лише тоді, коли змінилося фінансове значення** (напрямок, ціни входу/виходу/стопу, gross, комісія, своп, fee). Раніше будь-яке редагування перераховувало їх формулою, а для 61 імпортованої угоди збережений звірений net не збігається з формулою (комісію вже враховано) — розмітка тихо змінила б P/L (−119 сумарно) і R для 49 угод.

## Наслідки
Редагування списків чипів уже існуючої стратегії потребує екрана редагування стратегії, якого поки немає (є лише створення й дублювання).
