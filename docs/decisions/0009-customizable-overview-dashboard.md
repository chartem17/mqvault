# ADR 0009. Кастомізований дашборд «Огляд»

**Статус:** діє · **Дата:** 2026-11-06 (рішення власника)

## Рішення
Користувач сам збирає сітку віджетів статистики у вкладці «Огляд»: перетягування, зміна розміру, бічна бібліотека віджетів, кнопки «Скинути» та «Зберегти розкладку». Розкладка своя в кожного користувача й зберігається між сесіями (`dashboard_layout_preferences`, оптимістична ревізія). На мобільному — режим кнопок вгору/вниз. Чипи в «Розборі дня» беруться зі стратегії.

Порядок реалізації: віджети й реєстр → таблиця в Supabase → сітка → бібліотека → мобільна версія й дизайн.

## Наслідки
Нова «Головна» (короткі метрики, «Сьогодні», розбір дня) розвантажує «Огляд»; нові метрики додаються як віджети в реєстр, а не як жорстко розкладені блоки.
