# ADR 0008. Адаптивність

**Статус:** діє · **Дата:** 2026-11-07 (рішення власника)

## Рішення
Сайт повноцінно адаптується й масштабується під телефони та будь-який екран. Для платформо-залежної поведінки використовується єдиний хук `useMediaQuery` і константа `PHONE_QUERY` (`max-width: 767.98px`).

## Наслідки
- Нові екрани й віджети проєктуються з урахуванням телефона від початку; там, де перетягування незручне, потрібна альтернатива (наприклад, кнопки «вгору/вниз» для віджетів дашборда).

Код: `src/hooks/use-media-query.ts`; робота велася в гілці `feat/responsive`.
