# ADR 0004. Проп-правила спрощено; гілки етапів

**Статус:** діє · **Дата:** 2026-11-05 (рішення власника)

## Контекст
У різних проп-фірм різні правила (EOD, trailing, час закриття дня, balance/equity). Заповнювати їх надто довго, а застосунок не мав довіреної історії балансу й грошових потоків, щоб їх перевіряти.

## Рішення
- **Не підтримуємо** EOD/trailing і будь-які правила, специфічні для фірми. Шаблонів фірм не робимо.
- Лишаємо: ціль прибутку %, загальний ліміт збитку %, денний ліміт збитку %, мінімум торгових днів, необов'язкову фазу (Phase 1/2/3/Funded) як позначку.
- Кожна умова має стан `unknown` / `not_applicable` / `configured`; порожнє — `unknown`, а не «вимоги немає». Ліміти — це **ваші умови**, застосунок не виносить вердикту «пройдено/провалено».
- Етапи з'єднуються в лінійну гілку через `accounts.parent_account_id` («попередній етап»): спільний прогрес гілки, без автоматичних переходів між фазами.
- Редагування умов — з оптимістичним контролем (`expectedRevision`, 409 при розбіжності).
