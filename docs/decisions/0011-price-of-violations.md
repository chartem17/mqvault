# ADR 0011. «Ціна порушень»: проста контрфактична крива без заміни угод

**Статус:** діє · **Дата:** 2026-11-07

## Рішення
- У Strategy Control над правилами — блок «Ціна порушень»: дві накопичені криві R за період — «Як торгував» і «Якби за правилами» — та підсумок «Порушення коштували N R» (або «Угоди з порушеннями принесли N R», якщо вони були прибутковими). Нижче — розбивка за правилами, таблиця-альтернатива графіку й посилання на угоди з порушеннями в журналі.
- «Якби за правилами» = ті самі угоди без тих, що порушили хоча б одне активне правило. Пропущена угода нічим не замінюється; інших припущень немає.
- Денні ліміти (`max_trades_per_day`, `max_losses_per_day`) порушують лише угоди, відкриті **після** досягнення ліміту в той день; перші N угод дозволені. Рушій правил досі позначає доказами весь день — для кривої це було б нечесно. Решта правил використовує вердикт свого евалюатора по кожній угоді.
- Беруться лише угоди з відомим R; скільки без R — показується. Мало даних (< 20 угод з R або < 5 порушень) — мітка «Мало даних — висновок попередній».
- Округлення узгоджене: показані «як торгував − якби за правилами = −ціна» сходяться до сотих, а ціна дорівнює сумі рядків розбивки, коли правило одне.
- Підсумки «Без порушень / З порушеннями» у правій панелі тепер беруться з цього ж розрахунку (раніше складали середні по правилах і двічі рахували угоди з кількома порушеннями).
- Кольори двох ліній — окремі токени `--color-chart-clean` / `--color-chart-actual` для кожної теми, перевірені на розрізнення при дальтонізмі й контраст.
