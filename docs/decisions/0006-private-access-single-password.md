# ADR 0006. Приватний доступ одним паролем

**Статус:** діє, тимчасово (до повної авторизації)

## Контекст
Сайт поки приватний, один власник. Повна багатокористувацька авторизація — окрема велика робота (див. roadmap, «Безпека, авторизація, політики — наприкінці логіки»).

## Рішення
- Один пароль `VAULT_ACCESS_PASSWORD` (≥ 20 символів). Вхід на `/login` ставить httpOnly-cookie `vault_session` (підпис HMAC від пароля, 30 днів); зміна пароля розлогінює всіх. Basic-auth лишається для скриптів.
- Зміни (не GET) приймаються лише same-origin JSON.
- Власник робочого простору — єдиний `app_users.is_owner = true`; якщо їх не рівно один, API повертає 503.

## Наслідки
- Це **не** багатокористувацька авторизація: немає ізоляції між різними користувачами, немає особистого кабінету.
- Публічний запуск вимагає: повноцінної авторизації, прав доступу, тестів міжкористувацької ізоляції, privacy policy, а перед збереженням чужих паролів/ключів брокерів — пакета безпеки (шифрування секретів, політики, аудит).
