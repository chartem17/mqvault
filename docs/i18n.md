# Languages (i18n)

English is the default UI language; Ukrainian is the second one. The choice is kept in the `mq_locale` cookie
(1 year) and switched with the EN/UA button in the header and on the login page.

## How it works

- Source text is English. Components call `t("English text", { vars })` from `useI18n()`
  (`src/components/providers/i18n-provider.tsx`).
- Plurals: `tn(count, "{count} trade", "{count} trades")`. Ukrainian forms (one/few/many) live under the
  English plural key.
- Text defined outside components (catalogues, labels, lib messages) is wrapped in `msg("…")` and translated
  at render time with `t(label)`.
- Translations: `src/lib/i18n/uk.ts`, keyed by the exact English text. A missing key falls back to English.
- Dates and numbers use `intl` from `useI18n()` (`en-GB` / `uk-UA`).
- API routes return English error messages; the UI shows them through `t(error)`.

## Adding text

1. Write the English string in `t()` / `tn()` / `msg()`.
2. Add the Ukrainian translation to `src/lib/i18n/uk.ts`.
3. `npm test` fails if a `t()`/`msg()` string has no Ukrainian entry or if Ukrainian text is hard-coded
   anywhere outside the dictionary (`tests/i18n.test.mjs`).
