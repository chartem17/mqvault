# Приймальні перевірки проп-системи (вручну, на preview)

Не створюйте й не змінюйте реальні рахунки: заведіть тестовий і видаліть його після перевірки (через Undo-потік).

## Створення рахунку (4 комбінації)
- [ ] Особистий + без привʼязки; особистий + MT5: немає проп-блоку, умови не зберігаються.
- [ ] Проп + без привʼязки; проп + MT5: проп-блок видно, порожні поля = «не задано».
- [ ] Від'ємний або нульовий відсоток, відсоток >100, дробові дні — форма відхиляє з повідомленням.
- [ ] Після збереження й перезавантаження значення ті самі; інші рахунки не змінились.

## Умови
- [ ] Стани: «Ще не налаштовано» / «Такої вимоги немає» / «Така вимога є»; «немає» ховає умову, значення не стирається.
- [ ] Два вікна: зміна в одному, збереження в другому → 409 і блок збереження до «Перечитати».
- [ ] Ціль заповнена → прогрес за журналом; не заповнена → прогресу немає; режим «Усі рахунки» не показує спільний проп-ліміт.
- [ ] Немає жодних згадок EOD/trailing.

## Гілки
- [ ] Phase 2 з попереднім етапом Phase 1: у картці обох рахунків видно гілку та підсумок.
- [ ] Не можна вибрати рахунок, у якого вже є наступний етап; не можна зациклити (Phase 1 → Funded).
- [ ] «Немає» знімає привʼязку; видалення середнього етапу не ламає сусідів.
- [ ] Підсумок «разом» = сума net P&L етапів; торгові дні змінюються при зміні часового поясу.
